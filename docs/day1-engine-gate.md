# Day 1 Engine Gate (Unity vs Godot)

## Rule
- Weight: SDK fit 40, dev speed 40, stability/perf 20.
- Tie-break: if weighted score is tied, select Unity.

## How to run
```bash
npm run gate
```

The command writes `docs/engine-gate-result.json` with full scoring details.

## Current decision
- Selected engine: **Unity**
- Rationale: best monetization/analytics SDK compatibility for mobile hybrid-casual scope.
